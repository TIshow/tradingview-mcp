## 6. 効用関数 U（凍結）

```
U = w1·Return + w2·Sharpe − w3·DD − w4·Turnover + w5·Diversification

w1 = 0.5   w2 = 1.0   w3 = 1.0   w4 = 0.3   w5 = 0.5
```
※ バランス型：Sharpe と ドローダウンを同等に重視する。日本株契約と**同一の重み**を使う（市場間比較のため）。

- **既存ポートフォリオのバージョン**: `baseline_v1`（§10のベースライン5種）
- **評価指標**: `ΔU = U(既存 + s) − U(既存)`
- **推定誤差の扱い**: 点推定と併せて **95% 信頼区間**を保存。**区間が0を跨ぐ候補は採用しない**
- **同点時の優先順位**: ① 独立性が高い方 ② turnover が低い方 ③ 経済的説明が単純な方

## 9. 成功・棄却条件

**この研究の成功条件**（※「利益の出る戦略が見つかること」ではない）
- 全仮説が同一パイプラインを完走する
- 棄却・エラーを含め全試行が記録される
- 同じ入力で同じ結果を再現できる
- **生き残りゼロでも正常終了する**

**候補の採用条件（すべて満たすこと）**
1. §4 のハード条件をすべて通過
2. ΔU の95%信頼区間が **0を上回る**
3. Deflated Sharpe Ratio が **0** を上回る（試行数はレジストリ全体から取得）
4. **日本株契約 `RC-20260812-jp` でも同時に成立すること** ← 両市場AND条件

> **「日本株または米国株のどちらかで通ればOK」は禁止**。2回試して良い方を採るのは多重検定にあたる。
> 「米国株では成立したが日本株では成立しない」は正当な棄却理由（`market_dependent`）として記録する。
> 同一仮説を2市場で試した場合、**2試行としてカウント**する（レジストリは市場をまたいで共通）。

**プロジェクトの終了条件**: 実験予算の消化 または 封印期間の検証完了
